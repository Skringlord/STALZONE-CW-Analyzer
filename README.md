# STALZONE CW Analyzer

STALZONE CW Analyzer is a Windows tool that analyzes recorded Clan War footage using computer vision.

It tracks control-point ownership, hold times, transfers and total control score, then saves the results for later review.

The program works only with recorded video. It does not access game files, memory, network traffic, or the running game process.

## Download

Download the latest version from the **Releases** section of this repository.

Extract the ZIP archive and run:

`STALZONE CW Analyzer.exe`

Keep the `_internal` folder next to the executable.

## Features

- Automatic Clan War footage analysis
- Red / Blue / Neutral point detection
- 3-point and 6-point map support
- Hold-time and score calculation
- Ownership-transfer history
- Time and points advantage per control point
- Previous Results history
- GPU acceleration through DirectML
- CPU fallback if GPU acceleration is unavailable
